Task 1

Классы:
- `Animal` — базовый класс для всех животных  
- `Dog`, `Cat` — наследники  
- `Bowl` — миска с едой  
- `Main` — тестирование программы

Что делает программа:
- Животные умеют бегать и плавать (у котов ограничение — не плавают)
- У котов есть параметр «сытость»  
- Миска не может иметь отрицательное количество еды  
- Подсчитывается количество созданных животных, собак и котов

Task 2 — Shapes 

Классы и интерфейс:
- `Shape` — интерфейс с методами `getArea()` и `getPerimeter()`  
- `Circle`, `Rectangle`, `Triangle` — реализации интерфейса  
- `Main` — пример использования

Что делает программа:
- Каждая фигура имеет цвет заливки и цвет границы  
- Используются дефолтные методы интерфейса  
- В консоль выводятся все параметры фигур

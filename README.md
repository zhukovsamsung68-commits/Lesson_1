Task 1: Animals
Реализованы классы:
- `Animal` (базовый класс)
- `Dog` и `Cat` (наследники)
- `Bowl` (миска)
- `Main` (точка входа)

Функционал:
- Животные умеют бегать и плавать (у котов ограничение — не умеют плавать);
- У котов есть показатель сытости;
- Миска не может содержать отрицательное количество еды;
- Подсчитывается количество всех животных, собак и котов.

Task 2: Shapes (Interfaces)
Реализованы интерфейс и классы:
- `Shape` — интерфейс с методами `getArea()` и `getPerimeter()`
- `Circle`, `Rectangle`, `Triangle` — реализации интерфейса
- `Main` — пример использования

 Функционал:
- Каждая фигура имеет цвет заливки и границы;
- Используются дефолтные методы интерфейса;
- В консоль выводятся все параметры фигур.
